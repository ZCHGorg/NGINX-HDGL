## Quick Start (5 minutes)

### 1. Verify Files Exist

```bash
cd /path/to/shalom

# Check optimized files installed
ls -lh hdgl_transport_optimized.py       # New: async server, pooling
ls -lh hdgl_transport_client_optimized.py # New: connection pooling
ls -lh hdgl_audit_v0.4_performance.py   # New: performance tests
ls -lh hdgl_loadtest.py                 # New: load testing
ls -lh V0.4_OPTIMIZATION_HARDENING.md   # New: hardening guide
```

### 2. Update hdgl_host.py

```python
# OLD (v0.4 base)
from hdgl_transport import HDGLTransportServer, HDGLTransportClient

# NEW (v0.4 optimized)
from hdgl_transport_optimized import HDGLTransportServerOptimized as HDGLTransportServer
from hdgl_transport_client_optimized import HDGLTransportClientOptimized as HDGLTransportClient
```

### 3. Update to Async

```python
# OLD (synchronous)
def start_transport(self):
    self.transport.run()  # Blocking

# NEW (async)
async def start_transport(self):
    await self.transport.run()  # Non-blocking
```

### 4. Test Locally

```bash
# Run performance audit
python3 hdgl_audit_v0.4_performance.py

# Expected: All tests PASS (✓), >50K ops/sec, <10ms latency p99
```

### 5. Deploy

```bash
# Option A: Docker
docker build -t hdgl:v0.4-opt .
docker run -p 8444:8444 hdgl:v0.4-opt

# Option B: Systemd
systemctl restart hdgl

# Option C: Manual
python3 hdgl_host.py &
```

## Known Issues & Workarounds

### Issue: `ImportError: No module named 'hdgl_transport_optimized'`

**Cause**: File not in PYTHONPATH
**Fix**:
```bash
# Ensure files in same directory
cd /path/to/shalom
ls hdgl_transport_optimized.py
# Or add to PYTHONPATH
export PYTHONPATH=/path/to/shalom:$PYTHONPATH
```

### Issue: `AttributeError: 'StreamReader' has no attribute 'readexactly'`

**Cause**: Python version <3.7
**Fix**: Upgrade to Python 3.7+
```bash
python3 --version  # Must be 3.7+
python3.11 hdgl_host.py  # Use explicit version
```

### Issue: Connection pool exhaustion (too many open connections)

**Cause**: `LN_CLIENT_POOL_SIZE` too small or reuse limit too low
**Fix**:
```bash
export LN_CLIENT_POOL_SIZE=32
export LN_POOL_REUSE_LIMIT=256
```

### Issue: OOM (Out of Memory) under sustained load

**Cause**: Frame pool size too large or connection leak
**Fix**:
```python
# Reduce pool size
export LN_FRAME_POOL_SIZE=512  # From 1024

# Monitor for connection leaks
import gc
gc.collect()  # Force garbage collection
```
