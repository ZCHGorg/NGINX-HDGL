# HDGL v0.3 Architecture: Strand-Native HTTP Server

## Vision
Remove the NGINX layer entirely. Geometry flows through every decision — no config files, no weight lists, no upstream blocks. **Pure strand routing at L7.**

---

## Core Shift: Request → Strand → Authority

### v0.2 (Current)
```
Request arrives → NGINX (uses pre-computed weights) → upstream selected
(weights updated every ~30s by hdgl_ingress.py)
```

### v0.3 (Proposed)
```
Request arrives → phi_tau(path) → strand k → lattice.top_node_per_strand()[k]
(decision made per-request, not per-cycle)
```

---

## New Components

### 1. `hdgl_http_server_native.py` (replaces NGINX)
**Purpose:** Strand-aware HTTP/TLS server with built-in load distribution

**Architecture:**
```python
class HDGLHTTPServer:
    def __init__(self, lattice, fileswap, moire):
        self.lattice = lattice       # live topology
        self.fileswap = fileswap     # strand-addressed storage
        self.moire = moire           # request encoding
        self.tls_ctx = create_tls()  # native TLS

    async def handle_request(self, request):
        # L7 strand routing
        strand_idx = phi_tau(request.path)
        authority = self.lattice.top_node_per_strand()[strand_idx]

        # Option A: Local authority → serve from fileswap
        if authority == self.local_node:
            return self.fileswap.read(request.path)

        # Option B: Remote authority → proxy with strand affinity
        else:
            return await self.proxy_to(authority, request)

    async def proxy_to(self, authority_ip, request):
        """Route to authority node with connection pooling per strand."""
        conn = self.strand_pool[strand_idx].get_connection(authority_ip)
        return await conn.send(request)
```

**Features:**
- ✅ Per-request strand routing (no config)
- ✅ Native TLS/HTTP/2 or QUIC/HTTP/3
- ✅ Strand-affinity connection pooling
- ✅ Moire decoding on request body
- ✅ No NGINX reload cycles
- ✅ Direct lattice queries

### 4. Connection Pooling by Strand

```python
class StrandConnectionPool:
    def __init__(self, strand_idx, authority_ip):
        self.strand_idx = strand_idx
        self.authority = authority_ip
        self.connections = asyncio.Queue(maxsize=32)  # per-strand limit
        self.reuse_count = 0
        self.mismatch_count = 0  # track authority shifts

    async def get_connection(self, target_ip):
        """Return pooled connection, or create if authority shifted."""
        if target_ip != self.authority:
            # Authority changed — close stale, create new
            self.mismatch_count += 1
            self.authority = target_ip
            return await self.create_new(target_ip)

        try:
            return self.connections.get_nowait()
        except asyncio.QueueEmpty:
            return await self.create_new(target_ip)

    async def return_connection(self, conn):
        try:
            self.connections.put_nowait(conn)
            self.reuse_count += 1
        except asyncio.QueueFull:
            conn.close()
```

## Migration Path: v0.2 → v0.3

### Phase 1: Dual-Mode (v0.3-beta)
- Keep NGINX as fallback
- Run hdgl_http_server_native on alternate port (8091)
- Route subset of traffic to native server
- Compare latency, accuracy, stability

### Phase 2: Cutover (v0.3-stable)
- Remove NGINX from daemon entirely
- hdgl_http_server_native becomes primary HTTP listener (:80, :443)
- Disable hdgl_ingress.py (no more config generation)
- Fileswap + Native Server only

### Phase 3: Optimization (v0.3.1+)
- Add HTTP/3 (QUIC) support
- Implement strand-aware compression (different codecs per strand)
- Add request tracing with strand affinity headers
- Benchmark against NGINX + traditional balancing

## Performance Expectations

| Metric | v0.2 (NGINX) | v0.3 (Native) |
|--------|-------------|---------------|
| Config update delay | ~30s (daemon cycle) | 0s (per-request) |
| Per-request strand lookup | Via weight list | Direct phi_tau + lattice query |
| Connection reuse | NGINX upstream | Strand-affinity pool |
| TLS latency | NGINX termination | Native Go/Rust-like (async) |
| Geometric coherence | Indirect (weights→upstream) | Direct (strand→authority) |

**Goal:** No performance regression vs. v0.2; ideally < 2% latency increase due to per-request routing overhead.

## Key Decisions for v0.3

1. **Language:** Pure Python (asyncio) or hybrid (Rust for performance)?
   - Python: Simpler, integrates with existing stack
   - Rust: Better performance, but adds toolchain complexity

2. **Protocol:** HTTP/2 only, or HTTP/3 (QUIC) from day 1?
   - HTTP/2: Proven, adequate for most workloads
   - HTTP/3: Future-proof, but libraries still maturing

3. **Backward compatibility:** Keep v0.2 branch as stable fallback?
   - YES — v0.2 on main (stable), v0.3 as new default

## Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| TLS handshake overhead | Pre-pooled connections, session resumption |
| Per-request lattice query | Cache lattice state in server, update via gossip |
| Moire decoding latency | Optional (fallback to plaintext if needed) |
| Python asyncio limits | Monitor FD limit, use uvloop for performance |
| Authority shift during request | Circuit breaker pattern, retry with new authority |
